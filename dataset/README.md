# Dataset datasheet

Структура соответствует техническому заданию полуфинала.

- `images/real/` — реальные изображения, добавляемые участником только при наличии права использования.
- `images/synthetic/` — синтетика из `generator/generate.py`.
- `labels/` — текстовая разметка по одному файлу на изображение.
- `meta.csv` — метаданные, одна строка на один знак.

## Лицензирование
Перед сдачей для каждого реального источника укажите совместимую лицензию в `meta.csv`. Лица людей должны быть размыты/закрыты. Не включайте отладочный набор организаторов.

## Генерация
```bash
python dataset/generator/generate.py --count 5000 --seed 20261025 --root dataset
python dataset/validate_dataset.py --root dataset
```
